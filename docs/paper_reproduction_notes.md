# Paper reproduction notes

## Verified method

Hong et al., “Endmember-Guided Unmixing Network (EGU-Net): A General Deep Learning Framework for Self-Supervised Hyperspectral Unmixing,” IEEE Transactions on Neural Networks and Learning Systems (2021), DOI [10.1109/TNNLS.2021.3082289](https://doi.org/10.1109/TNNLS.2021.3082289). The paper describes E-Net and UR-Net as jointly trained streams with partial parameter sharing and says the spatial-spectral variant shares late 1×1 convolutions. In the released EGU-Net-ss source, the third 1×1 abundance feature convolution and its batch normalization are genuinely shared. The E-Net final 32→C convolution and UR-Net's separate C-output stride-8 transposed convolution are distinct parameters. This port follows those explicit source tensors where the paper's description is less specific. UR-Net also uses spatial 5×5 and 3×3 convolutional stages, average pooling, and nonlinear transposed-convolution reconstruction. Abundances use softmax sum-to-one and nonnegativity constraints. The total objective is E-Net classification plus whole-image reconstruction loss.

The official TensorFlow source specifies channels 224→256→128→32→5 for its examples, spatial kernels 5×5 then 3×3, and three factor-two average-pooling operations. This implementation parameterizes the spectral-band and material counts for Samson (156 and 3). For dimensions not divisible by eight, the latent abundance feature grid is expanded to `ceil(H/8)×ceil(W/8)` before the stride-8 transposed convolution. This makes PyTorch's output shape valid while preserving the requested output dimensions; the original sample implementation hard-codes divisible 200×200 dimensions.

The paper reports Adam, a polynomial schedule with base learning rate 0.1 and power 0.99, 200 epochs, a batch equal to the pseudo-endmember count, and reconstruction coefficient 1.0. Its prose calls 0.9 the dropout rate, but the released TensorFlow script passes `keep_prob=0.9` to `tf.nn.dropout`, which means a dropout probability of 0.1. This implementation follows the executable source: elementwise dropout probability 0.1 in both streams, and Xavier initialization for convolution filters. The first DGX run showed spatial convolution weights collapsing nearly to zero with Adam at LR 0.1; the current settings therefore use LR 0.001 as a stability alternative, while recording the paper LR as `PUBLISHED_LEARNING_RATE`. This is a documented deviation requiring fresh training and further tuning; it is not claimed as the paper's hyperparameter. The official source uses Adam with an exponential-decay schedule in its training function despite the paper prose. Batch size is configurable and defaults to 128 for practical memory use, rather than claiming exact reproduction of the full-bundle batch. No independent validation-selection procedure is supplied for this single-scene workflow, so `best.pt` is based on training total loss and is not an unbiased generalization estimate.

## Preprocessing adaptation and limitations

The paper describes partially overlapping local blocks, local VCA with a HySime-estimated count, and clustering to aggregate bundles, with cluster count around 20% of pixels. The repository distributes VCA and a MATLAB bundle-generation example, but that example is a synthetic-data script using fixed nonoverlapping 5×5 tiles, fixed five endmembers per tile, and SUnSAL labels against a caller-provided dictionary. The network script itself expects precomputed pure/mixed spectra and labels and hardcodes a 200×200×224 cube. The provided project implements VCA, local bundle extraction, clustering, and nonnegative least-squares abundance fitting against a global VCA dictionary. This is an explicit self-supervised adaptation: HySime and the paper's specific overlap/block defaults are not implemented, and labels are approximate VCA-dictionary fractions rather than labels derived from reference endmembers. Do not interpret it as exact reproduction of the authors' dataset preprocessing.

The paper's Eq. (6) prints a binary cross-entropy expression, while the released EGU-Net-ss script uses softmax cross-entropy. This port follows the released network script and uses softmax cross-entropy. Training also uses the learned UR-Net decoder's mean squared error. Diagnostics showed the learned decoder can reconstruct the scene without requiring its abundance maps to be physically meaningful. The troubleshooting branch therefore adds (1) a linear mixture consistency loss using scene-derived VCA prototypes, and (2) pixelwise abundance supervision from NNLS-normalized fits against those same unlabeled VCA prototypes. Ground-truth abundances/endmembers remain evaluation-only. These are explicit extensions to the source objective, not an exact paper reproduction. The L2 coefficient is set to 0.00001 after 0.005 coincided with spatial-feature collapse in the DGX run. The abundance head also uses bilinear upsampling followed by a 1x1 convolution to avoid non-overlapping stride-8 output blocks.

The paper's aRMSE is `sqrt(mean_pixels(mean_materials((A - Ahat)^2)))`. Endmembers are recovered by nonnegative least squares from `X ≈ E Ahat` solely for spectral visualization/evaluation, as described in Eq. (12). Ground-truth abundance and endmember data are never passed into preprocessing or training. The Samson dataset was absent from the inspected workspace, so no Samson run or numerical research result is claimed. Place the two MATLAB files under `data/raw/` before running the notebook. Verify variable names/dimensions if your copies differ.
